# G0.5 Bring-Up — 2026-10-02

## Scope

This is a separately labeled G0.5 FM fallback, not a substitute identity for the
blocked RoboDojo pi0.5 checkpoint. No policy-controlled robot action, complete
native policy episode, benchmark success, or paid API call is established here.
The inference input is the retained legal RGB/proprio observation from
`classify_objects__standard__g0__l0`, in the development partition.

Independent checkpoint verification, environment installation and local CPU
tests were overlapped. Stateful sessions and simulator episodes remain isolated.
GPU 1 is the policy device; GPU 0 remains reserved for simulation.

## Inference Container

The source loader calls `torch.load(..., map_location=device)` on the entire
training checkpoint, including optimizer state. The published model state alone
contains 946 FP32 tensors totaling 13,505,768,784 bytes (12.58 GiB).

`scripts/multibench/export_inference_checkpoint.py` exports those same tensors,
without optimizer/scheduler/EMA state, retaining scalar training metadata. This
is container repacking, not training or weight quantization. The original remains
untouched. The export receipt records:

- Original checkpoint hash:
  `a923ba1fbff409f0103f6e204e76eb0cedde60ad45615526e7c9fe59099019e1`.
- Model-only container hash:
  `3332c28a6feefbb8eec0309cda20b343e30566b40574fef5723f4351390ad799`.

The bounded probe explicitly overrides `model.model_weights_to_bf16=true` at
runtime. This differs from the saved FP32 inference setting and must remain in
the bound provider identity. Other source defaults, including FM ten-step
denoising, predicted horizon 32 and exposed prefix 16, remain unchanged.

## Negative Results

1. G0.5 model construction succeeded, but the source FLA path failed at inference:
   `chunk_gated_delta_rule() got an unexpected keyword argument 'chunk_size'`.
   This is a source/kernel API compatibility failure, not task failure.
2. The documented PyTorch linear-attention fallback reached action prediction,
   but strict action decoding rejected a gripper opening outside `[0,1]`.
   No action was executed, no implicit clipping was applied, and no native
   episode was started. This needs raw-range evidence before selecting a fix.

`scripts/multibench/probe_g05.py` performs one cold and three warm independent
saved-observation inferences by default. It records raw actions, validation
errors, timings and peak memory; an invalid action makes the command exit 2.
The PyTorch fallback is labeled explicitly, not presented as optimized FLA speed.

## Next Gate

The final bounded probe produced four 16-action chunks (one cold, three warm).
Load time was 48.37 s, cold inference 8.85 s, and warm inference
0.868 / 0.767 / 0.765 s. Peak allocated memory was 11,812,070,400 bytes
